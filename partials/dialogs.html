GF / DMを切り替える

画面上部のGF / DMボタンで表示するスキルを切り替えます。

スキル対象を同期する

MENU →「スキル対象同期」（管理者は「公式サイト同期」）の手順に従い、公式ページで同期用ブックマークを実行します。管理者はGF / DMの同期対象を選び、スキル対象のみ・全曲（最高難易度のみ）・全曲（全パート）・GF / DM別の難易度幅指定から同期方法を選択できます。

FCマークやオプションは手動で登録します。

スコアを登録する

スキル対象外の曲は「登録」タブの「＋登録」から登録できます。曲名は直接入力するほか、「頭文字」と「曲名」のプルダウンから選択できます。

同期がうまくいかない場合も、手動で登録できます。登録曲をタップすると内容を編集できます。

ライバルを登録する

ユーザーリストからGF / DMそれぞれ最大10人まで登録と解除ができます。

「ライバル管理」では登録しているライバルが一覧で確認できます。

登録曲詳細を見る

登録曲をタップすると、以下の情報を確認できます。

  • 歴代の自己ベスト
  • 過去作の達成率一覧/今作の達成率比較（記録があるバージョンのみ）
  • コメント一覧（コメントがあるバージョンのみ）
  • 全ユーザーのオプションの使用割合
  • ライバルとの達成率比較
スキル対象ランキングを見る

MENU →「スキル対象ランキング」から、指定したスキルの幅でスキル対象に入っている割合、平均スキル値、自分のスキルとの比較が確認できます。

現在のスキル対象を共有・保存する

MENU →「現在のスキル対象を共有・保存」からGF / DM / 両方を選び、画像の共有、履歴への保存、保存して共有ができます。

保存履歴と比較する

保存履歴の「比較」を押すと、当時と現在のスキル対象を曲名・パート単位で比較できます。履歴をタップすると当時の画像を確認して共有できます。

タグで登録曲を整理する

MENU →「タグ設定」で自分用のタグを最大10個作成できます。登録曲の編集画面で曲ごとに複数のタグを付けられます。

「登録」タブのタグフィルタで絞り込めます。

曲データ一覧を見る

MENU →「曲データ一覧」で曲名順、GF難易度順、DM難易度順を選び、フィルタで「すべて／HOT／OTHER」を指定して「一覧を表示」を押します。

難易度順では下限・上限も指定できます。曲をタップすると全パートの難易度が見られ、難易度の数値をタップするとその曲・パートのスコアを登録・編集できます。

お気に入りリストを使う

「曲データ一覧」で曲を開き、難易度表の左上にある1・2・3をタップすると、対応するお気に入りリストに追加できます。

選択済みのボタンをもう一度タップすると解除できます。曲は複数のリストに入れられます。MENU →「お気に入りリスト1～3」から各リストを開けます。

リスト名は上部の入力欄で変更して「名前を保存」を押します。曲名順は昇順、難易度順は降順が初期設定です。

並び順・難易度の下限と上限を変えると自動で絞り込まれ、難易度をタップすれば登録・編集できます。

公式スキルランキングを見る

MENU →「公式スキルランキング」で、表示中のバージョンのGF / DMランキングを確認できます。100位ごとにページを切り替えられます。

「最終更新」にデータの更新日時が表示されます。

掲示板を使う

「掲示板」タブから、バージョン共通のスレッドを閲覧・投稿できます。スレッドタイトルで検索でき、登録から24時間経過したユーザーは新規スレッド作成や投稿ができます。

画像は1投稿につき1枚まで添付できます。投稿者本人は自分の投稿を編集・削除できます。問題のある投稿は「通報」から管理者へ知らせることができます。

メールアドレス・電話番号・本名などの個人情報、誹謗中傷、公序良俗に反する内容、別サイト・サービスなど全ての勧誘行為は禁止です。

マイページを使う

ユーザー名・パスワード・X IDの変更、ログアウトができます。アカウントの削除は元に戻せません。

新規登録時はユーザー名にメールアドレス・電話番号・本名などの個人情報を入力しないでください。

管理者が個人情報に該当すると判断したアカウントは削除対象となる場合があります。

機能設定を変更する

MENU →「機能設定」でライトモード、曲一覧の横並び表示、文字サイズ、GFのデフォルトオプション、登録曲やX IDの公開設定を変更して「保存する」を押します。

ユーザーを切り替える

マイページの「ユーザー切り替え」で、この端末に追加したアカウントへ切り替えられます。追加時にログインが必要です。パスワードは端末に保存しません。

要望・不具合を報告する

MENU →「要望・不具合報告」で種類を選び、内容を入力して送信できます。過去の報告もこの画面で確認できます。

運営を支援する

MENU →「運営を支援する」から任意で支援できます。支援の有無で利用できる機能は変わりません。
